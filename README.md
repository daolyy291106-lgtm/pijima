# Nhà Pijama

Website tĩnh, sẵn sàng để đăng lên GitHub Pages.

## Cấu trúc
- `index.html`: trang web chính
- `images/`: toàn bộ hình ảnh của website

## Đăng GitHub Pages
Đưa toàn bộ thư mục này lên một repository GitHub, sau đó vào **Settings → Pages** và chọn:
- Source: **Deploy from a branch**
- Branch: **main**
- Folder: **/ (root)**
